# Insightly — AI-Powered Data Analysis

**Turn your data into meaningful insights.**

Insightly is an AI-powered data analysis platform designed to help users explore datasets, understand trends, generate visualizations, and extract actionable insights using natural language.

Whether you're working with business data, academic records, financial reports, surveys, or other structured information, Insightly aims to make data analysis more accessible and intuitive.

## ✨ Features

- **AI-Powered Analysis** — Ask questions about your data in natural language.
- **File Uploads** — Import supported data files for analysis.
- **Data Visualization** — Generate charts to identify patterns and trends.
- **Statistical Insights** — Explore summaries, comparisons, rankings, and key metrics.
- **Smart Recommendations** — Use AI-generated observations to support data-driven decisions.
- **Multiple Use Cases** — Suitable for education, business, research, reporting, and more.

## 🚀 Getting Started

1. Open the deployed Insightly website.
2. Upload a supported data file.
3. Ask a question or select an analysis task.
4. Review the generated results, insights, and visualizations.

For best results, use clear column names and provide specific instructions.

## 📂 Supported File Formats

Insightly is designed to work with supported formats including:

- CSV
- TSV
- Excel
- JSON
- TXT
- Text-based PDF

Scanned PDFs and image-based documents may not be readable without OCR support.

## 🛠️ Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js and Express
- **AI Integration:** Google Gemini API
- **Security:** Server-side API key configuration, HTTP security headers, and request rate limiting
- **Deployment:** GitHub and Render

## 🔐 Security and Privacy

- API credentials should remain on the server and must never be published in frontend code or GitHub.
- Avoid uploading confidential, sensitive, or personally identifiable information unless you understand the platform's data handling and AI-provider policies.
- Public access does not mean unlimited usage. AI availability depends on API quotas and hosting limits.

## ⚠️ Current Limitations

- AI-generated results may contain errors and should be checked before making important decisions.
- Some complex requests may require clearer instructions or better-structured data.
- Free hosting and AI usage are subject to provider limits.
- Available analysis features depend on the uploaded file and the application's current capabilities.

## 💡 Vision

Insightly aims to simplify data analysis by combining conversational AI, visualizations, and accessible insights in one platform.
